Domain discovery asks what the system must understand before deciding how to implement it.

For Monad, that means examining concepts such as semantic identity, representations, claims, evidence, authority, provenance, execution, verification, native systems, and relationships among engineering artifacts.

## Read this phase through

  <Card title="Requirements" href="/docs/artifacts/requirements">Inspect the normative expectations discovered across the domain.</Card>

</Cards>

## Boundary

A domain-discovery conclusion can later be revised. The current model belongs in System and accepted Artifacts; this page only provides the phase-oriented path through them.
