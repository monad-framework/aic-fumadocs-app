# Implementation

Implementation is where specifications encounter real toolchains, repositories, integrations, runtime constraints, partial failures, and developer workflows.

For Building Monad, the interesting story is not merely which files changed. It is how implementation pressure confirms, challenges, or forces revision of the upstream model.

  <Card title="Project" href="/docs/project">Use current project/work documentation for authoritative execution context.</Card>
  <Card title="Specifications" href="/docs/artifacts/specifications">Read the contracts implementation is expected to satisfy.</Card>

</Cards>

## Boundary

Journal records may describe incomplete or failed implementation attempts. Current implementation truth belongs in the codebase and authoritative documentation; Changelogs communicate meaningful published deltas.
