Verification asks what evidence justifies a claim that the system satisfies an expectation.

This phase matters because Monad deliberately distinguishes **execution success** from **verification success**. A command can run successfully while the intended postcondition remains unsatisfied.

## Boundary

A narrative statement that something worked is not verification. Building Monad should link to the evidence and verification record that supports the claim.
